泰坦尼克号幸存者 问题

数据集简介

本次使用的数据集为Titanic - Machine Learning from Disaster | Kaggle，为Kaggle的竞赛题，比赛选择了泰坦尼克号作为背景，并提供了样本数据以及测试数据，要求我们使用机器学习创建一个模型，预测哪些乘客在泰坦尼克号沉船中幸存下来

数据集预览

打开数据集我们发现该数据集内，每位乘客拥有12项属性

名称 属性
Passengerld 唯一标识符
Survived 是否存活，0否、1是
Pclass 客舱等级，分为1、2、3级
Name 姓名
Sex 性别，分为male、female
Age 年龄
SibSp 船上乘客的兄弟姐妹/配偶数量
Parch 船上乘客的父母/子女数量
Ticket 船票号
Fare 船票价格
Cabin 客舱编号
Embarked 上船的港口编号，分为S、C、Q

数据处理

查看数据

通过分析发现：数据共有1309行

其中缺失数值的有：年龄(Age)、船票价格(Fare)、客舱编号(Cabin)、登船港口(Embarked)

数值类有:

  1. Age总数据1046条，缺失了1309-1046=263条，缺失率20%
  2. Fare总数据1308条，缺失1条

字符串类有：

  1. Cabin总数据295条，缺失了1039-295=1014条，缺失率77.5%
  2. Embarked总数据1307条，缺失了2条

缺失数据填充

接下来我们对于缺失数据进行填充

  • 对于数值类我们使用fillna函数取中间值进行填充
  • 对于Embarked我们采用最常见的类别填充
  • 对于Cabin我们使用U来填充

数据特征工程与特征提取

在 Titanic 生存预测中，数据预处理和特征工程是提高模型准确率的关键步骤。

性别

乘客的性别是生存概率的重要指标。我们将性别映射为数值：

  • 男性 → 1
  • 女性 → 0

这样机器学习模型可以直接理解性别的差异。

客舱等级

Pclass 代表舱位等级，也可能反映乘客的社会地位。我们同样使用 One-hot 编码，将其转为三个独立特征：

  • Pclass_1
  • Pclass_2
  • Pclass_3

头衔

乘客姓名中包含头衔（Title），如 Mr、Mrs、Miss 等，这能反映社会身份和年龄特征。
我们从 Name 中提取头衔，并将罕见或等价头衔归为五类：

  • Mr
  • Miss
  • Mrs
  • Master
  • Rare（稀有头衔，如贵族、军衔、医生等）

登船港口

乘客的登船港口也可能影响生存率。由于它是类别型变量，我们使用 One-hot 编码，将每个港口拆分为独立的二值特征：

  • Embarked_C
  • Embarked_Q
  • Embarked_S

家庭特征

  • 家庭成员数量：FamilySize = SibSp + Parch + 1
  • 是否独自一人：IsAlone = 1 if FamilySize == 1 else 0

客舱位置

Cabin 信息可以提供乘客所在甲板的位置。我们取 Cabin 的首字母作为 Deck，并用 One-hot 编码：

删除无用项

特征名 类型 来源 / 处理方式 说明
Sex 数值型 原始 Sex → 男1/女0 性别对生存率影响大
Embarked_C / Embarked_Q / Embarked_S 类别型（One-hot） 原始 Embarked → One-hot 编码 登船港口，不同港口生存率不同
Pclass_1 / Pclass_2 / Pclass_3 类别型（One-hot） 原始 Pclass → One-hot 编码 舱位等级，反映社会地位和生存概率
Title_Mr / Title_Miss / Title_Mrs / Title_Master / Title_Rare 类别型（One-hot） 从 Name 提取头衔，并合并稀有类别 头衔可反映年龄、性别和社会身份
FamilySize 数值型 SibSp + Parch + 1 家庭成员总数，家庭大小可能影响生存率
IsAlone 数值型 FamilySize == 1 → 1，否则 0 是否独自一人登船，对生存率有影响
Deck_A ~ Deck_U 类别型（One-hot） 从 Cabin 提取首字母 → One-hot 乘客所在甲板位置，对逃生可能性有影响
Age 数值型 原始 Age → 均值填充缺失值 乘客年龄
Fare 数值型 原始 Fare → 均值填充缺失值 票价，反映舱位和社会经济状况

模型优化与预测

最佳模型的选择理由和评估结果

选择随机森林作为最佳模型的主要原因在于：

  1. 高基准得分：在未经调优的五种模型中，Random Forest 的基准准确率最高（0.8357）。
  2. 抗过拟合性：作为集成模型，它通过多数投票机制结合多个弱分类器，有效提高了模型的泛化能力和鲁棒性。
